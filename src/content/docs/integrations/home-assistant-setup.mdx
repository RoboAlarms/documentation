The RoboAlarms integration connects one Home Assistant server directly to the panel on the local network. It needs no MQTT broker and no cloud account. You install the integration in Home Assistant, and then you pair it on the panel's screen.

<Aside type="note" title="Before you start">
- You need Home Assistant 2026.3 or newer and an administrator account. To install Home Assistant, see [Prepare Home Assistant](/integrations/home-assistant-host/).
- You need the panel's system master code or installer code. A partition master cannot change **Integrations**.
- Home Assistant and the panel must be on the same network, or the network must allow TCP port 6054 from Home Assistant to the panel.
- Disarm every partition.
</Aside>

The integration is a custom integration with the name **RoboAlarms**. It is not a Home Assistant app. Its GitHub repository has the name `ha-addon`.

## Install the integration with HACS

<Steps>

1. In Home Assistant, open **HACS**.
2. Click the three-dot menu, and then click **Custom repositories**.
3. Type `https://github.com/RoboAlarms/ha-addon` as the repository.
4. Choose **Integration** as the type, and then click **Add**.
5. Find **RoboAlarms** in HACS and download it.
6. Restart Home Assistant.

</Steps>

If HACS is not installed, follow the [HACS setup guide](https://www.hacs.xyz/docs/use/). HACS asks for its own GitHub authorization. This authorization is not a part of the panel pairing. For more information, see [custom repositories](https://www.hacs.xyz/docs/faq/custom_repositories/) in the HACS documentation.

### Install the integration manually

<Steps>

1. Download the integration from the [RoboAlarms releases](https://github.com/RoboAlarms/ha-addon/releases).
2. Copy the `custom_components/roboalarms` folder into the `custom_components` folder of the Home Assistant configuration.
3. Check that the file path is `config/custom_components/roboalarms/manifest.json`, with no extra folder.
4. Restart Home Assistant.

</Steps>

## Turn on Home Assistant on the panel

<Steps>

1. On the panel, push **Settings > Integrations**.
2. Enter the system master code or the installer code.
3. Under **Smart home**, push **Home Assistant**.
4. Turn on **Home Assistant**.

   The line under the switch shows **On · ready to pair**.

</Steps>

<PanelShot src="/images/panel/ha-pair-ready.png" alt="Home Assistant page on the panel with the switch on, the status On · ready to pair and the Pair with Home Assistant button" caption="With the switch on, the panel shows Pair with Home Assistant." size="medium" />

The panel now announces itself on the network, so Home Assistant can find it.

## Add the panel in Home Assistant

<Steps>

1. In Home Assistant, open **Settings > Devices & services**.
2. If **RoboAlarms** shows under **Discovered**, click **Add**. Then click **Submit** to confirm the panel.
3. If the panel does not show, click **Add integration** and search for **RoboAlarms**.
4. Type the panel's IP address in **Host**. Keep **Port** at `6054`.

   To find the IP address on the panel, push **Settings > Wi-Fi and network**, and then push the connected network.

5. Click **Submit**.

   Home Assistant shows **Pair with the panel**.

</Steps>

<PanelShot src="/images/home-assistant/connect.png" alt="Home Assistant dialog Connect to your panel with the Host and Port fields" caption="Type the IP address that your panel shows; the address in the image is an example." size="small" />

Discovery works only when Home Assistant and the panel are on the same subnet. On a routed network, type the address.

## Pair and compare the codes

<Steps>

1. On the panel, push **Pair with Home Assistant**.
2. Enter the system master code or the installer code.

   The panel keeps pairing open for two minutes.

3. In Home Assistant, click **Submit** on **Pair with the panel**.

   Home Assistant and the panel each show a six-digit code.

4. Compare all six digits on the two screens.
5. If the codes are the same, push **Yes, allow** on the panel.
6. If the codes are not the same, push **No, reject**. Do not pair.

</Steps>

<PanelShot src="/images/home-assistant/open-pairing.png" alt="Home Assistant dialog Pair with the panel, which asks you to push Pair with Home Assistant on the panel" caption="Open pairing on the panel first, and then click Submit in Home Assistant." size="small" />

<PanelShot src="/images/home-assistant/compare-code.png" alt="Home Assistant shows a six-digit code that must be the same as the code on the panel" caption="Home Assistant shows the code; compare it with the code on the panel." size="small" />

<PanelShot src="/images/panel/ha-pair-code.png" alt="Panel asks Does Home Assistant show this code? with the buttons No, reject and Yes, allow" caption="Push Yes, allow only when all six digits are the same." size="medium" />

<Aside type="danger" title="Warning">
Do not allow a pairing when the codes are not the same. A different code can mean that another device on the network is between the panel and Home Assistant.
</Aside>

The pairing code is not an alarm code. You cannot use it to disarm. The panel never gets your Home Assistant password.

## Finish in Home Assistant

<Steps>

1. If Home Assistant shows **Name and assign**, check the names of the panel and the zones.
2. Choose an **Area** for a device if you want to.
3. Click **Skip and finish** to keep the names, or finish with your changes.

</Steps>

<PanelShot src="/images/home-assistant/name-assign.png" alt="Home Assistant Name and assign dialog with the panel and its zones" caption="Each zone is a device under the panel, and you can give each one an area." size="small" />

You can change the names and areas later in Home Assistant.

<Aside type="tip" title="Check the result">
On the panel, the line under **Home Assistant** shows **On · connected and paired**. In Home Assistant, **Settings > Devices & services > RoboAlarms** shows the panel and its zones as devices.
</Aside>

<PanelShot src="/images/home-assistant/connected.png" alt="Home Assistant RoboAlarms integration page with the panel and three zone devices" caption="The panel and each zone show as devices; the numbers depend on your panel." />

<PanelShot src="/images/panel/ha-pair-paired.png" alt="Home Assistant page on the panel with the status On · connected and paired and the Unpair button" caption="The panel shows On · connected and paired when Home Assistant is connected." size="medium" />

The panel trusts one Home Assistant server. To move to another server, unpair the first one on the panel. For more information, see [Troubleshoot Home Assistant](/integrations/home-assistant-troubleshooting/#unpair-or-move-home-assistant).

## If it does not work

| Problem | Do this |
| --- | --- |
| **RoboAlarms** is not in **Add integration**. | Check the folder of the integration, and restart Home Assistant. |
| Home Assistant shows **Could not reach the panel**. | Turn on **Home Assistant** on the panel. Check the IP address and that the network allows TCP port 6054. |
| Home Assistant shows **The panel isn't pairing right now**. | Push **Pair with Home Assistant** on the panel, and then try again. |
| Home Assistant shows **Pairing timed out on the panel**. | Open pairing on the panel again, and continue within two minutes. |
| The panel shows **Switch the integration on first**. | Turn on **Home Assistant** on the panel, and then push **Pair with Home Assistant**. |

For more problems, see [Troubleshoot Home Assistant](/integrations/home-assistant-troubleshooting/).
