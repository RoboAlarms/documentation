The panel can connect to Home Assistant, to an MQTT broker and to phone notification services. Each connection is optional and has its own settings. The panel makes all alarm decisions itself, also when a connection stops.

All connections are under **Settings > Integrations** on the alarm panel. The system master code or the installer code opens the page. A partition master cannot change it.

<PanelShot src="/images/panel/integrations-list.png" alt="Integrations page with Home Assistant and MQTT under Smart home, and ntfy and Pushover under Alerts to your phone" caption="Each connection has its own row and shows its state under its name." />

## Choose a connection

| | Home Assistant | MQTT | Phone notifications |
| --- | --- | --- | --- |
| **Use it to** | See and control the panel in Home Assistant. Use Home Assistant sensors as zones and Home Assistant devices on **Smart Home**. | Send status and events to Node-RED, your own scripts or other broker clients. | Send alarms, troubles and other events to a phone. |
| **You need** | A Home Assistant server on the same network, and the RoboAlarms integration. | An MQTT broker. | The ntfy app or a Pushover account. |
| **How it connects** | Directly on the local network, encrypted. You pair it on the panel's screen. | Through the broker, encrypted or not. | Through the internet to ntfy or Pushover. |
| **Arm and disarm** | Yes, with a user code. | Yes, if you allow it. The panel checks the code. | No. |
| **Data to the panel** | Only the Home Assistant entities that you share. | Commands only. | None. |
| **Set it up** | [Install and pair Home Assistant](/integrations/home-assistant-setup/) | [Connect an MQTT broker](/installer/mqtt/) | [Phone notifications](/installer/notifications/) |

You can use more than one connection at the same time. Home Assistant does not need MQTT. If Home Assistant is paired, the panel sends no MQTT discovery messages, so Home Assistant does not show the panel twice.
