Use this page only if you do not have Home Assistant yet. If Home Assistant already runs and opens in a browser, continue with [Install and pair Home Assistant](/integrations/home-assistant-setup/).

<Aside type="note" title="Before you start">
- Choose a computer for Home Assistant. Home Assistant runs all the time, so a dedicated device is best.
- Connect it to the same network as the panel.
</Aside>

## Choose an installation

For a first installation, Home Assistant recommends **Home Assistant Operating System**. It includes the Supervisor, apps, updates and backups. You can install it on a Home Assistant Green, a Raspberry Pi or a supported x86-64 computer. Follow the official [installation guide](https://www.home-assistant.io/installation/) for your hardware.

On Windows or macOS, Home Assistant Operating System runs in a virtual machine. Follow the [Windows guide](https://www.home-assistant.io/installation/windows/) or the [macOS guide](https://www.home-assistant.io/installation/macos/).

## Finish the first setup

<Steps>

1. Start the Home Assistant computer.
2. In a browser, open `http://homeassistant.local:8123/`.

   If this address does not open, use the IP address that your router shows for the computer, followed by `:8123`.

3. Wait while the screen shows **Preparing Home Assistant**.
4. Make the owner account. Keep its user name and password in a safe place.
5. Set your home location.
6. Finish the other prompts of the [onboarding](https://www.home-assistant.io/getting-started/onboarding/).

   Home Assistant opens its default dashboard.

</Steps>

The owner account is an administrator. You need an administrator to install the RoboAlarms integration.

## Linux alternative: Home Assistant Container

Use Home Assistant Container only if you already manage a Linux computer and Docker. You need Docker Engine 23.0.0 or newer. A container installation has no Supervisor and no apps, and you update the container yourself.

This Compose example follows the official [Linux Container guide](https://www.home-assistant.io/installation/linux/). Save it as `compose.yaml` on the Linux computer. Change `Europe/Amsterdam` to your time zone. Then start it with `docker compose up -d`.

```yaml
services:
  homeassistant:
    container_name: homeassistant
    image: "ghcr.io/home-assistant/home-assistant:stable"
    volumes:
      - ./config:/config
      - /etc/localtime:/etc/localtime:ro
    restart: unless-stopped
    stop_grace_period: 60s
    privileged: true
    network_mode: host
    environment:
      TZ: Europe/Amsterdam
```

The `./config` folder keeps the Home Assistant configuration when the container is made again. `network_mode: host` lets Home Assistant find the panel on the local network. Docker Desktop on Windows or macOS does not support this network mode in the same way, so use a virtual machine there. The RoboAlarms integration uses the network and needs no USB device.

When the container runs, open `http://<address-of-the-linux-computer>:8123/` and finish the same onboarding.

<Aside type="tip" title="Check the result">
Home Assistant opens its dashboard in the browser, and you can sign in with the owner account.
</Aside>
