This guide describes the current RoboAlarms software. Use this page to find the version that you use.

## What this guide describes

| Software | What it is |
| --- | --- |
| **RoboAlarms Panel** | The firmware on the panel. Keypad panels use the same firmware. |
| **Flasher** | The program for your computer that installs and updates the firmware over USB. |
| **Panel Manager** | The pages that the panel shows in a browser. They come with the panel firmware. |
| **Home Assistant integration** | The RoboAlarms integration that you install in Home Assistant with HACS. |

## Find your version

| Software | Where to find the version |
| --- | --- |
| Panel | Open **Settings > About**. The top row shows the version. |
| Keypad panel | Open **Settings > About** on the alarm panel, and then push **Software update**. The **Keypads** section shows the version of each keypad. |
| Panel Manager | Panel Manager has the same version as the panel. |
| Home Assistant integration | In Home Assistant, open **Settings > Devices & services > RoboAlarms**. The integration details show the version. |
| Flasher | The Flasher shows the firmware release before it installs. |

## Older or newer software

Labels and options can be different on older or newer software. If a label in this guide is not on your screen, update the panel. See [Software updates and SD card](/user/updates-storage/).

Use panel software and a Home Assistant integration that work together. The release notes of the integration tell which panel software it needs.

For news about new versions, see [RoboAlarms updates](https://roboalarms.com/updates/).
