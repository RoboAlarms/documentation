## Choose your guide

**User Guide** — Everyday operation, zones, chime, alerts, Smart Home, panel automations, household settings and updates.

**Installer Guide** — First setup, access, zone programming, connected services and a practical handover checklist. This edition covers software setup; mounting and wiring are outside its scope.

**[Flasher Guide](/flasher/)** — The computer app: USB connection, first installation, updates, whole-flash backups and recovery, connected parts and diagnostics.

**[Panel Manager Guide](/panel-manager/)** — The panel's browser interface: accounts and access, the remote keypad, household settings, installer programming, network changes and updates.

**[Integrations](/integrations/)** — Connect Home Assistant, share sensors and device controls, use MQTT, and set up phone notifications. Start with the overview to choose the connection you need.

Start with the [task index](/reference/task-index/) if you already know what you want to do. Search also finds control names and messages shown by the panel.
