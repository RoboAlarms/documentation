Panel Manager is the browser interface served by the panel itself. It works over your local network or an authorized VPN. It does not require a cloud account, Home Assistant, or a companion server. The panel uses HTTPS and checks every request against the signed-in person's role.

## First connection

You need someone at the panel who can enter Installer mode, the installer code, and a computer on the same local network or an authorized VPN. All partitions must be disarmed and no alarm can be active before you change configuration.

1. On the touchscreen, open **Settings > About > Installer** and enter the installer code.
2. Turn on the **Panel Manager** switch. New installations have browser access off.
3. Record the HTTPS address and **certificate SHA256 fingerprint** shown on the panel.
4. On the computer, open that HTTPS address. Compare the browser certificate fingerprint with the value on the panel before trusting the panel's self-signed certificate.
5. Create or enable a browser sign-in as described in [Browser accounts and permissions](/panel-manager/accounts/).

When browser access is running, plain HTTP redirects to HTTPS. Turning **Browser access (this Panel Manager)** off closes the service and ends browser sessions. It also turns off **Developer tools**; local Installer access is needed to enable browser access again.

## Understand the limits

The panel enforces permissions on each request; hiding a menu item is not the security boundary. Standard users see only their assigned partition status. Non-installers see zone names, sensor kinds, and status wording, but not sensor programming. The installer can manage all users; system and partition masters can manage only users allowed by their authority and partition scope. Integrations are for the system master and installer.

While any partition is armed or an alarm is active, configuration changes are refused. You can still use the remote keypad because it operates the panel's own screen, change your own browser password, or sign out. Normal signed updates can be installed by a system master, partition master, or installer when disarmed.

The remote keypad is a real control path to the panel. The person at the touchscreen sees a red banner and can pause the browser session. See [Remote keypad](/panel-manager/remote-keypad/) before using it to enter a code or change a protected setting.
