Use this page to change the Wi-Fi network or the IP address of the panel in Panel Manager. The panel tries new settings for two minutes first. If you do not confirm them, the panel goes back to the old settings by itself.

<Aside type="note" title="Before you start">
- Sign in as a partition master, the system master or the installer.
- Disarm every partition.
- Write down the current address of the panel, for example https://192.0.2.42.
- Have a way to reach the panel's screen, in case the browser loses the panel.
</Aside>

## Change the Wi-Fi network

<Steps>

1. Click **Network**.
2. Under **Wi-Fi network**, click **Find networks**, and click a network in the list.

   You can also type the **Network name**.

3. Type the **Password** of the network. Leave it empty only for an open network.
4. Click **Connect**.

   Panel Manager asks **Change Wi-Fi network?**.

5. Check the values, and confirm.

   The panel joins the new network. The browser can lose the connection.

6. Within two minutes, open Panel Manager again and sign in.

   If the address changes, the page shows a link to the new address. Open it in the same browser.

7. Click **Keep the new settings**.

</Steps>

<Aside type="tip" title="Check the result">
Panel Manager shows **New network settings kept.** The top card on **Network** shows the new Wi-Fi network.
</Aside>

## Set a fixed IP address

<Steps>

1. Click **Network**.
2. Under **IP address**, turn on **Fixed IP address**.

   When it is off, the router gives the panel its address (DHCP).

3. Type the **IP address**, the **Subnet mask**, the **Router (gateway)** and the **DNS server**.

   The **Second DNS server** is optional.

4. Click **Apply**.

   Panel Manager asks **Change the IP address?**.

5. Check the values, and confirm.
6. Within two minutes, open the panel at its new address, for example https://192.0.2.50, in the same browser.
7. Sign in, and click **Keep the new settings**.

</Steps>

Ask the person who manages your network for the values. An address that another device uses stops the panel from working on the network.

## Check the connection

Under **Connection check**, click **Run the check**. The panel checks in order: Wi-Fi, the IP address, the router, name lookup (DNS), the internet, the time server and the connected services. If one check fails, the later checks are skipped. The first failed check shows what to fix.

## If the panel goes back

If you do not click **Keep the new settings** within two minutes, the panel goes back to the old settings. A restart during the two minutes also brings back the old settings.

<Steps>

1. Wait until the two minutes are over.
2. Open Panel Manager at the old address.
3. Correct the values, and try again.

</Steps>

Do not send a second change while the panel tries the first one.

## If it does not work

| Problem | Do this |
| --- | --- |
| The browser does not reach the new address. | Check that the computer is on the same network as the panel. Wait two minutes, then open the old address. |
| The browser warns that the certificate changed. | Compare the fingerprint in the browser with the fingerprint on the panel, in **Settings > About > Installer** under **Panel Manager**. |
| The page does not load, but the panel answers. | An ad blocker can block the panel's address. Allow the address in the blocker. Open the address with `https://`. |
| You do not know the panel's address any more. | On the panel, open **Settings > Wi-Fi and network**. See [Network and time](/user/network-time/). |
| Panel Manager is off. | The installer turns on **Panel Manager** at the panel, in **Settings > About > Installer**. |
