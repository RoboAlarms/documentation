Use this page when the Flasher does not find a panel, stops a job or shows an error. The page also explains the advanced tools.

When a job stops, the Flasher shows what happened and what to do next. Read the message first. Most messages also say if something was changed.

## Advanced tools

Click **Advanced tools** at the top of the window. Click **Back to guided setup** to go back.

<PanelShot src="/images/flasher/flasher-panels-and-ports.png" alt="Flasher Panels and ports page with COM5, No RoboAlarms software yet, and COM6, RoboAlarms 0.5.9, Chosen" caption="Panels and ports lists every panel that is plugged in. Click Choose to work with one." size="medium" />

| Tool | What it does |
| --- | --- |
| **Panels and ports** | Lists everything plugged into the computer. Click **Choose** to use a panel. Click **Look again** to ask a panel again. Looking at a panel never restarts it. Click **Show other ports** to see ports that do not look like a panel. |
| **Console** | Opens the panel's service console without a restart. Use the quick commands or type a command. Click **Save log** to keep the text. Click **Restart panel** only when you want to restart the panel. The Flasher never types keypad codes. |
| **Hardware** | Shows and changes the connected parts. Click **Apply and restart the panel** to save them. It also records raw 433 MHz pulses. See [Connected parts](/flasher/connected-parts/). |
| **Zigbee module** | Puts the radio software on the Zigbee module, while the module is out of the panel. |
| **Backups** | Makes and restores whole-flash backups. See [Back up, reset and restore](/flasher/backups/). |
| **Software** | Shows the firmware version and the build for each board. You can choose another release channel or open a `.roboflash` file that you were given. You can also drop the file on the window. |
| **Logs** | Opens the Flasher's own log folder. Add the log to a bug report. |

The Console works only when the panel's software has a service console. Software from the Stable, Beta and Alpha channels has no service console. A Dev build has it, and is for test panels only.

**Automatic (recommended)** in **Software** chooses the steadiest release for the board: Stable, then Beta, then Alpha. A Dev build needs its own confirmation. Do not use a Dev build on a panel that protects a home.

The Flasher keeps its files in these folders:

| Files | Folder |
| --- | --- |
| Backups | `Documents\RoboAlarms\Backups` |
| Radio recordings | `Documents\RoboAlarms\Captures` |
| Logs | `%LOCALAPPDATA%\RoboAlarms\Flasher\logs` |

## If something goes wrong

### The panel is not found or the port does not open

| Problem | Do this |
| --- | --- |
| **Connect** finds no panel. | Slide the **POWER** switch to on. Connect the computer to **UART0**, not to **USB2.0**. Use a cable that carries data, and connect it straight to the computer. Click **Nothing showing up?** for more help. |
| Windows shows no COM port for the panel. | The CH340 USB driver is missing or did not start. Install the driver, then plug the panel in again. |
| **The port could not be opened.** | Close other programs that use the port, for example a serial monitor or another Flasher window. Then try again. |
| **That board was unplugged. Plug it in again.** | Plug the cable in again, and choose the panel again. If the job had started, run it again. |
| **Nothing on** the port **takes what the Flasher sends.** | Unplug the panel, plug it back in, and try again. |

### The check or the job stops

| Problem | Do this |
| --- | --- |
| **The board did not answer its loader.** | Check that the cable carries data and that the panel has power. If it still fails, hold **BOOT** on the board, push and release **RESET**, then release **BOOT**. Click **Check this panel** again. |
| The board or the build looks wrong. | Stop. Click **Not this board? Choose it yourself** only if you know the exact board. A build that is grayed out does not fit the chip or the flash size. Do not force it. |
| The panel is armed, in Installer mode or has an alarm. | Finish that on the panel. Then click **Look again**. The Flasher does not restart a busy panel. |
| **Identifying restarts the board, so it waits.** | The panel is busy, and a check would restart it. Disarm the panel and close Installer mode, then check again. Nothing was changed. |
| **The Flasher's look at the panel is out of date.** | The Flasher checks that the panel is idle before every restart. Click **Look again**, then start the job again. Nothing was changed. |
| **The panel did not answer, so the Flasher can't tell whether it is idle.** | Check on the panel's screen that it is disarmed and idle. If it is stuck, unplug it and plug it back in. |
| **The panel's firmware does not answer, so it cannot be updated in place.** | The panel's software has no service console. Update it on its screen or in [Panel Manager](/panel-manager/updates/). Choose Install only if you want to erase the panel. |
| **The connection to the board was lost.** | Check the cable, plug it back in, and run the same job again. |
| **What was written does not read back the same.** | Try again. If it fails again, use another USB cable or port. |

### After the install or update

| Problem | Do this |
| --- | --- |
| The write stopped before the end. | Keep the panel powered. Run the same job again: Install after an install, Update after an update, Restore after a restore. Do not run Install after an update: it erases the settings. |
| **The panel did not come back after its restart.** or the screen stays black | The panel had too little power. Connect **USB2.0** to a phone charger with 5 V and 2 A or more. Switch the panel off and on with **POWER**. Then check **Advanced tools > Console**. |
| A part is not found. | Compare the part and its place with the drawing in **Full wiring**. Correct it in **Advanced tools > Hardware**. See [Connected parts](/flasher/connected-parts/). |
| **This panel's firmware can't set up these parts.** | The firmware on the panel does not support the part. Use a firmware version that supports it. |
| You need the maker's demo software back. | Restore the backup that the Flasher made before the first install. See [Back up, reset and restore](/flasher/backups/#restore-a-backup). Without that backup, the demo cannot come back. |

<Aside type="note">
The Flasher cannot burn eFuses, turn on secure boot or flash encryption, or change the panel's C6 coprocessor. It never enters keypad codes.
</Aside>
