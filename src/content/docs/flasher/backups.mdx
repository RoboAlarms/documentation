The Flasher makes a whole-flash backup of a panel: the firmware, the settings and the logs together. Use this page to make a backup, to reset a panel to factory defaults, and to put a backup back on a panel.

A whole-flash backup is not the configuration backup of Panel Manager. For a backup of the settings only, see [Installer programming](/panel-manager/installer/#back-up-or-restore-the-settings).

## Choose the right task

| Task | What it does |
| --- | --- |
| **Install RoboAlarms** | Backs up the panel if you keep the box ticked. Then it erases the chip and installs RoboAlarms. See [Install RoboAlarms](/flasher/install/). |
| **Update to RoboAlarms** | Writes new firmware and keeps the codes, users, zones, Wi-Fi and history. See [Update RoboAlarms](/flasher/update/). |
| **Reset to factory defaults** | Erases the whole panel and installs RoboAlarms fresh. The codes, users, zones, Wi-Fi, integrations and event history are gone. |
| **Restore** | Writes a backup over the whole panel. The firmware, settings and logs of the panel are replaced. |

## Make a backup

<Aside type="note" title="Before you start">
- The panel is connected to the computer. See [Flasher](/flasher/).
- Disarm every partition and close Installer mode.
</Aside>

<Steps>

1. Click **Advanced tools**.
2. Click **Backups**.

   <PanelShot src="/images/flasher/flasher-backups.png" alt="Flasher Advanced tools Backups page with No backups yet, Back up this panel now and Open the Backups folder" caption="Back up this panel now makes a whole-flash copy of the chosen panel." size="medium" />

3. Click **Back up this panel now**.

   The Flasher asks **Back up the whole flash?**.

4. Click **Back up**.

   The panel restarts into its loader. The Flasher reads the flash into a file and checks it. Then the panel starts again. This takes a few minutes.

5. Keep the cable and the power connected until the backup shows in the list.

</Steps>

<Aside type="tip" title="Check the result">
The **Backups** page lists the new backup with its date. Click **Open the Backups folder** to see the files.
</Aside>

Each backup has two files in the folder `Documents\RoboAlarms\Backups`: a `.bin` file and a `.json` file with the same name. The `.json` file describes the chip, the flash size, the board and the checksum. Keep the two files together. Keep a second copy in a safe place.

A backup of a new panel is the only way back to the maker's demo software. The Flasher makes this backup in **Install** when **Back up the panel first** is ticked.

## Reset to factory defaults

<Aside type="caution" title="Caution">
Reset erases the codes, users, zones, Wi-Fi, integrations and event history for good. Make a backup first if you need any of it.
</Aside>

The Flasher offers a reset only for a panel that runs RoboAlarms and answers the Flasher.

<Steps>

1. In **Guided setup**, connect and check the panel, then open the **Update** step.
2. Click **Reset to factory defaults**.
3. To keep a copy first, tick **Keep a copy of the panel as it is now**.

   This box is off by default.

4. Tick **Erase everything on this panel**.
5. Click **Reset to factory defaults**.

   The Flasher asks **Reset this panel to factory defaults?**.

6. Click **Erase and reset**.

</Steps>

The Flasher erases the whole flash and installs RoboAlarms again. Then the panel starts the first setup. See [Run the first setup](/installer/first-setup/).

## Restore a backup

<Aside type="caution" title="Caution">
A restore replaces everything on the panel. It does not merge settings. The current firmware, settings and logs of the panel are gone.
</Aside>

<Steps>

1. Connect the panel, and click **Advanced tools**.
2. Click **Backups**.
3. Click **Restore…** beside the backup.

   The Flasher asks **Restore this backup?** and shows the name and date of the backup.

4. Check the name and the date.
5. If the backup came from another board, check that you want it on this board. Then tick **Restore it onto this board anyway**.
6. Click **Restore**.

   The Flasher writes the backup, checks what it wrote, and restarts the panel.

7. Keep the cable and the power connected until the job finishes.

</Steps>

<Aside type="tip" title="Check the result">
The panel starts with the firmware and settings of the backup. A backup of the maker's demo starts the demo again.
</Aside>

## If it does not work

| Problem | Do this |
| --- | --- |
| **This backup has no description file next to it (.json).** | Put the `.json` file in the same folder as the `.bin` file, with the same name. The Flasher restores only backups that it made. |
| **The backup file is damaged (its checksum does not match).** | Use another copy of the backup. |
| The Flasher says that the backup is from another chip or flash size. | Use a backup of this kind of board. The Flasher does not restore it on this board. |
| **The backup came back short.** | Try again. Nothing was erased. |
| A restore stops or the cable comes out. | Connect the same panel, and restore the same backup again. |
