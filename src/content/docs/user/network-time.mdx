Use this page to connect the panel to Wi-Fi, find a network problem, and set the time and language of the panel.

<Aside type="note" title="Before you start">
- You need a system master, partition master or installer code to change the network, time zone, language, region or time server.
- Anyone can change the clock format.
- All partitions must be disarmed, with no alarm. Settings open only then.
</Aside>

## Join or change Wi-Fi

<Steps>

1. Open **Settings > Wi-Fi and network**.
2. Enter your code, if the panel asks for one.
3. Push a network under **Networks nearby** or **Other networks nearby**.

   If the network is not in the list, push **Look again**.

4. Enter the Wi-Fi password, and then confirm.

   The network moves to the top of the page and shows **Connected**.

</Steps>

<PanelShot src="/images/panel/network-wifi-list.png" alt="Wi-Fi and network page with a connected network at the top and other networks nearby below" caption="The connected network is at the top, with its signal and IP address." />

<Aside type="tip" title="Check the result">
The top row shows the network name, **Connected** and the IP address of the panel.
</Aside>

The alarm keeps working without the network. If the panel does not connect, ask the person who manages the router for the correct password.

## Check the connection

<Steps>

1. Open **Settings > Wi-Fi and network**.
2. Push the connected network at the top.

   The panel shows the network page with the **IP address**.

3. Push **Check the connection**.

</Steps>

<PanelShot src="/images/panel/network-joined.png" alt="Network page with IP address, IP address settings, DNS server, Check the connection and Forget this network" caption="Push Check the connection to test each step from the Wi-Fi to the connected service." size="medium" />

The check tests these steps in order: **Wi-Fi**, **Address**, **Router**, **Name lookup**, **Internet**, **Time server** and **Connected service**. Start with the first step that fails. It shows where the problem is. The check does not change any settings.

<PanelShot src="/images/panel/network-check-passed.png" alt="Connection check results with a green check mark beside Address, Router, Name lookup, Internet and Time server" caption="Each step shows a check mark when it passes." size="medium" />

**Connected service** tests the connection to the configured service only. It does not test the devices that Home Assistant shares, or phone notifications.

### Use a fixed address

For most home networks, keep **IP address settings** at **Automatic**. The router then gives the panel its address. Use **A fixed address** only when the person who manages the network asks for it.

<Steps>

1. On the network page, push **IP address settings**.
2. Push **A fixed address**.
3. Enter the **Address**, **Subnet mask** and **Router** that the network manager gives you.
4. If you want, enter a **DNS server** and a **Second DNS server**.

</Steps>

Use an address outside the automatic address range of the router. No other device can use the same address. After the change, the panel checks the connection again by itself.

## Set the time zone, language and time server

<Steps>

1. Open **Settings > Time and language**.
2. Enter your code, if the panel asks for one.
3. Push **Time zone**, and then push the time zone of the panel.
4. Under **Language**, push **Language**, and then push a screen language.
5. Push **Region** to set how dates and numbers look.
6. Push **Clock**, and then push **Automatic**, **12-hour** or **24-hour**.

</Steps>

<PanelShot src="/images/panel/network-time-language.png" alt="Time and language page with the date and time, Time zone, Clock, Language and Region rows" caption="The top row shows the date and time and where the clock gets its time." size="medium" />

The time zone also sets the daylight saving changes. **Clock** changes only how this panel shows the time.

The panel gets its time from a time server on the internet. To use another server, push **Time server** under **Advanced**, and then type the server name. If you leave it empty, the panel uses `pool.ntp.org`.

## Set the date and time by hand

Some panels have a clock module that keeps the time without the network. On these panels, you can set the date and time by hand.

<Steps>

1. Open **Settings > Time and language**.
2. Push the date and time row at the top.
3. Push the day in the calendar. To change the month, push the arrows or the month name.
4. Set the **Hour** and **Minute** rollers.
5. On a 12-hour clock, push **AM** or **PM**.
6. Read **The clock will say**, and then push **Set**.

</Steps>

<PanelShot src="/images/panel/network-set-clock.png" alt="Set the date and time sheet with a calendar, hour and minute rollers and The clock will say line" caption="The line at the bottom shows the date and time that the clock will get." />

**Cancel** keeps the clock as it is. When the panel is online again, the internet time replaces the time that you set by hand. If the row does not open, the panel has no clock module.

## Without Wi-Fi

The alarm keeps working without Wi-Fi. These functions need the network:

- The Home Assistant connection and the devices it shares. A Home Assistant zone without a connection is not treated as closed.
- Phone notifications.
- Update checks.
- Time from the internet. A clock module keeps the time while the panel is offline.

## If it does not work

| Problem | Do this |
| --- | --- |
| The network is not in the list. | Make sure the router is on and near enough, and then push **Look again**. |
| The panel does not connect. | Check the Wi-Fi password with the person who manages the router. |
| A step in the connection check fails. | Start with the first step that fails. See [Troubleshooting](/reference/troubleshooting/). |
| The time is wrong. | Check the **Time zone**. Then check that **Time server** passes in the connection check. |
| **Time and language** does not open. | Enter a system master, partition master or installer code. |
