An automation is a short rule that the panel keeps and runs by itself. It has one trigger and one or two actions. For example: when the front door opens, turn on the porch light.

Automations run on the panel itself, with or without Home Assistant. Home Assistant must be online only when an action uses one of its devices. For advanced automations with conditions, waits or many steps, use Home Assistant.

<Aside type="note" title="Before you start">
- You need a system master code or the installer code. A partition master code cannot change automations.
- All partitions must be disarmed, with no alarm.
- For a device action, the device must be shared with the panel. See [Smart Home](/user/smart-home/).
</Aside>

Automations keep running while the panel is armed or in alarm. You can change them only when the panel is disarmed and quiet.

## Create an automation

<Steps>

1. Open **Settings > Automations**.
2. Enter a system master or installer code.
3. Push **Add an automation**.

   The panel shows some ready ideas, such as **Turn on a light when a door opens**, and **Start from scratch**.

4. Push an idea, or push **Start from scratch**.
5. Under **When should it run?**, push a trigger.
6. Under **What should it do?**, push an action.
7. To add a second action, push **Add a second action**.
8. If you want, set **Only between** or **Turn it off after**.
9. Read the sentence that the panel shows for the rule, and then save it.

</Steps>

<PanelShot src="/images/panel/automations-rule.png" alt="An automation page: When Front Door opens, Only between 6:00 PM to 6:00 AM, Turn on Porch Light, Turn it off after 10 minutes" caption="The page shows the trigger under When and the actions under Then." size="medium" />

<Aside type="tip" title="Check the result">
The rule shows in the list as a sentence, such as **When Front Door opens**. Push **Try it now** on the rule page to run its device actions once.
</Aside>

### Triggers

| Trigger | When it runs |
| --- | --- |
| **When the panel is armed** | After exit time ends. Choose Away, Stay, Night or **Any of them**. |
| **When the panel is disarmed** | When a partition is disarmed. |
| **When an alarm sounds** | When an alarm sounds. It never runs for a silent alarm. |
| **When a fire or CO alarm sounds** | When a fire or CO alarm sounds. |
| **When a door or window opens** | When the zone opens. You can also choose a motion or water sensor. |
| **When a door or window closes** | When the zone stays closed for 10 seconds. |
| **At a time of day** | At the time you choose, on the days you choose. It runs once a day at most. |

Silent alarms and duress codes never start an automation.

### Actions

A device action can turn a light, switch or fan on or off, or toggle it. It can lock or unlock a lock, and open, close or stop a cover. It can open or close a water valve, turn a thermostat off or run a scene. **Arm the panel** and **Disarm the panel** are also actions.

A rule has up to two actions, with one action for each device. An arming action must be the only action. Scripts and sirens are not automation actions.

**Only between** limits a rule to a time window. **Turn it off after** turns a device off again after a time. The panel keeps up to 16 automations.

## Arm at a set time

Use **At a time of day** with the **Arm the panel** action to arm a partition automatically. The panel always warns before it arms.

<Steps>

1. Open **Settings > Automations**, and then push **Add an automation**.
2. Push **Start from scratch**.
3. Push **At a time of day**, and then set the time and the days.
4. Push **Arm the panel**.
5. Choose the partition and **Away**, **Stay** or **Night**.
6. Set **Warn first** to a time from 1 to 15 minutes. The default is 5 minutes.
7. Save the rule.

</Steps>

During the warning, **Security** and the status bar show the arming time. The panel sounds the chime once a minute.

<PanelShot src="/images/panel/automations-arm-warning.png" alt="Security screen with the card Arming Night at 10:30 PM, Set by an automation, and a Put off button" caption="The card at the top right shows when the panel arms and has the Put off button." />

If a zone is open when the time comes, the panel does not arm. **Bypass open zones** lets the rule bypass open burglary zones and arm. A sensor with a trouble still stops the arming. Fire, CO and 24-hour zones are never bypassed. A bypassed zone is watched again when it closes, and each bypass ends at the next disarm.

<Aside type="danger" title="Warning">
Turn on **Bypass open zones** only if you accept an open zone without protection. A bypassed zone does not cause an alarm while it is open.
</Aside>

**Bypass open zones** is available only when the installer turns on **Allow less secure automations**. It is off in each new rule.

### Put off an automatic arming

<Steps>

1. On **Security**, push **Put off**.
2. Push **An hour later** or **Not tonight**.

   During the day, the second choice is **Not today**.

3. Enter a code.

</Steps>

<PanelShot src="/images/panel/automations-put-off.png" alt="Put off arming dialog with An hour later and Not tonight" caption="Each choice shows when the panel arms instead." size="small" />

Any valid code can put off the arming for an hour. **Not tonight** and **Not today** need a code that can disarm that partition. A wrong code counts toward the keypad lockout. The warning starts again five minutes before the new time.

An automatic arming does not run while the panel clock is not set. A missed time does not run later. If the panel restarts during the warning, it skips that arming.

## Safety and permissions

An automation acts as the person who saved it last. When it runs, the panel checks the current role of that person again. A system master can save arming and disarming actions. The installer can save device actions, but cannot save arming or disarming actions. When you edit a rule, you become its new maker.

Disarming, unlocking, opening and stopping are less secure actions. The installer turns them on or off with **Allow less secure automations** at **Settings > About > Installer > Delays and arming**. When it is off, the panel does not offer these actions. A saved rule with such an action stays in the list, but it does not run.

Before you save some rules, the panel asks you to confirm:

- A scene: the panel cannot see what a scene does. A scene can unlock or open something without a code.
- A switch that turns on or toggles: use it only for a light or a plug. Never use it for a switch that opens a door, gate or garage.
- A less secure action after a door, window, motion or alarm trigger. The panel shows what happens, for example: "Anyone who opens Front Door will unlock Front Door Lock."

The panel refuses some rules. A rule cannot disarm after an alarm or fire trigger. A rule cannot disarm a partition that its own trigger armed. An automation can never silence an alarm, start a panic alarm or change the arming mode of an armed partition.

## Change, pause, test or delete a rule

<Steps>

1. Open **Settings > Automations**, and then push the rule.
2. To pause the rule, turn off **Use this automation**.
3. To change the rule, push its trigger or action, and then save it.
4. To run its device actions once, push **Try it now**.
5. To delete the rule, push **Delete this automation**, and then confirm.

</Steps>

**Try it now** does not run an arming action. A paused rule stays in the list but does not run.

<PanelShot src="/images/panel/automations-list.png" alt="Automations list with five rules, one of them showing Didn't work at 8:02 AM" caption="Each rule shows its last result under its actions." size="medium" />

The list shows when each rule ran last and its result, such as **Didn't work**. The panel keeps this result until it restarts. Open the rule to read the reason.

## Examples

- **Porch light:** when the front door opens, turn on the porch light. Set **Only between** to evening hours.
- **Lock up:** when the panel is armed Away, lock the front door.
- **Night arming:** at 10:30 PM every day, arm Night after a 5-minute warning.
- **Water leak:** when the water sensor opens, close the water valve.

## If it does not work

| Problem | Do this |
| --- | --- |
| **Settings > Automations** is not in the list. | The software on this panel does not have automations. Ask the installer. |
| The panel shows **Automations can be changed once the system is disarmed**. | Disarm all partitions and silence any alarm. Then open **Settings** again. |
| A rule shows **On · waits until the clock is set**. | Set the clock in **Settings > Time and language**. See [Wi-Fi, network and time](/user/network-time/). |
| A rule shows **Can't run** and a reason. | Open the rule and do what the reason says. A rule from newer software can only be deleted. |
| A device action did not work. | Make sure the device is online in Home Assistant and still shared. Look at the device before you try an unlock or open again. |
| The automatic arming did not happen. | Open the rule and read its result. Look for open zones and troubles in the partition. |
| The rule ran, but the result is wrong. | The panel sends each action once. Look at the device itself before you change the rule. |
