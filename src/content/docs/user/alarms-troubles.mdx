An **alarm** reports an alarm condition. A **trouble** reports a fault that needs attention. The two are not interchangeable.

## When an alarm appears

Read the alarm type and named zone. If there may be a real emergency, follow your household emergency plan and contact the appropriate emergency service. Operating the screen does not itself guarantee that anyone has been notified.

For a known false burglary alarm, enter an authorized disarm code and select the **check mark**. Check the resulting state and review the named zone. Do not assume that silencing the panel also canceled a report already delivered to another service.

<PanelShot src="/images/panel/alarm-memory.png" alt="Panel displaying alarm memory after disarming" caption="Alarm memory records that an alarm happened; it is different from a currently sounding alarm." />

After reviewing the cause, use **Clear alarm** when offered, enter an authorized code and submit with the check mark. It clears alarm memory for the affected partition; it does not make an active sensor fault disappear.

## Read and acknowledge a trouble

1. Open **Troubles** on the left rail.
2. Read the fault and its explanation.
3. Correct the underlying problem, or contact the installer.
4. Use the offered acknowledgment control and enter a code if asked.

<PanelShot src="/images/panel/troubles.png" alt="Troubles page listing current faults and an acknowledgment control" caption="Read the individual fault before acknowledging it." />

Acknowledging a trouble does not repair it. A continuing fault can remain listed or return. Use the [troubleshooting table](/reference/troubleshooting/) for network, sensor, storage and code problems.

## Review what happened

**Activity** is the event history. It shows events in time order, with the partition where relevant. Silent events are excluded from the public Activity view, including Panel Manager's Activity page.

<PanelShot src="/images/panel/activity.png" alt="Activity list with chronological alarm events" caption="Activity helps you identify what changed and when." />

## Emergency controls

The **Panic** rail item opens the **Emergency** page. Available actions depend on configuration. The interface uses a deliberate hold to activate an emergency action; a brief touch does not complete it.

Do not activate emergency controls just to explore the page. Arrange any test with the installer and everyone who might receive an alert. This guide does not claim automatic police, fire or medical dispatch.
