RoboAlarms brings the alarm state, your zones and household settings together on one touchscreen. Start here if someone has already configured the system for you.

## Read the Home screen

The large status card tells you whether this keypad's partition is **Disarmed**, counting down or armed. A partition is an area that arms separately from other areas. **Ready to arm** means the required zones in this partition are ready for the selected arming mode. **Not ready** means a zone needs attention.

<PanelShot src="/images/panel/home-ready.png" alt="RoboAlarms Home screen with Disarmed status and Away, Stay and Night choices" caption="Home is the starting point for everyday operation." />

The left rail gives you quick access to:

| Control | What you use it for |
| --- | --- |
| **Home** | Arm, disarm and see the current state |
| **Zones** | Find an open sensor or review bypasses |
| **Activity** | Read recent everyday events |
| **Troubles** | Understand a fault and acknowledge it |
| **Chime** | Turn door-opening sounds on or off |
| **Panic** | Open the Emergency page |

The gear at the top opens **Settings**. Settings are unavailable while any partition is armed or in alarm. A code is requested when you enter a protected section. The installer may have assigned this keypad to one partition; ask which area it controls if the screen does not show the area you expect.

## Learn these three tasks first

1. [Arm and disarm](/user/arming-disarming/) with your own code.
2. [Find an open zone](/user/zones-bypass/) before leaving.
3. [Read an alert](/user/alarms-troubles/) without confusing an alarm with a system fault.

Ask the installer which doors have an entry delay and which sensors are active in **Night**. These choices depend on your installation.

If this panel has compatible device control enabled, [Smart Home](/user/smart-home/) explains device tiles, Favorites, Rooms and arranging the Home screen. The device controls shown depend on the configured device sources and the panel build. [Panel automations](/user/automations/) covers rules saved on the alarm panel; these are separate from Home Assistant automations and scheduled arming.

## Enter a code

Type the digits, then select the **check mark** to submit. Code lengths can differ, so typing the last digit alone does not submit. Use the delete key to correct a mistake.

Repeated incorrect codes can temporarily lock the keypad. If you do not know your code, ask the person who manages household users rather than guessing.

## Wake the screen

Tap the screen saver to return to the panel. It shows the time and alarm state while the screen is dimmed. You can change its timing and brightness in [Screen and sound](/user/display-sound/). On builds with a ready voice pack, announcements can speak panel status and approved zone names; find their controls at **Settings > Screen and sound > Announcements**.
