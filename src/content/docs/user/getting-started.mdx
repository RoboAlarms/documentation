Use this page to learn the parts of the panel screen. Start here if someone already set up the panel for you.

## The Security screen

The panel shows the **Security** screen when you start it. This screen shows the alarm state and the arming tiles. If the start screen is set to **Smart Home**, the panel shows **Smart Home** while it is disarmed. An alarm always shows the **Security** screen.

<PanelShot src="/images/panel/home-tour.png" alt="The Security screen. The rail is on the left, the top bar is at the top, the state ring is in the middle and the Away, Stay and Night tiles are on the right" caption="The numbers in the list below name each area of the Security screen." />

1. **The rail.** The column on the left side. Push an item to open its screen: **Security**, **Zones**, **Smart Home**, **Activity** and **Panic**.
2. **The state ring.** It shows the alarm state with a color and an icon. Green means **Disarmed** and ready. Yellow means that something needs attention.
3. **The state text.** Below the ring, the panel shows the state, for example **Disarmed**. The line below it tells you more, for example **Ready to arm** or the name of an open zone.
4. **The arming tiles.** **Away**, **Stay** and **Night**. Push a tile to arm. When the panel is armed, a code pad to disarm takes the place of the tiles.
5. **The date.** On the left of the top bar. A message can show in its place, for example **Factory codes · Tap to change**.
6. **The status icons.** The Wi-Fi icon and the battery level of the panel. When the panel has a trouble, a yellow trouble count shows here too.
7. **The time.**
8. **The chime button.** A bell. Push it to turn the chime on or off. A crossed-out bell means that the chime is off.
9. **The settings button.** A gear. Push it to open **Settings**.

## The rail

| Item | What it opens |
| --- | --- |
| **Security** | The alarm state, the arming tiles and the code pad. See [Arm and disarm](/user/arming-disarming/). |
| **Zones** | A list of all zones and their state. A number on the icon shows how many zones need attention. See [Zones and bypass](/user/zones-bypass/). |
| **Smart Home** | Lights, locks and other devices. This item shows only when the panel has devices. See [Smart Home](/user/smart-home/). |
| **Activity** | The event history of the panel. See [Alarms, troubles and activity](/user/alarms-troubles/#review-what-happened). |
| **Panic** | The **Emergency** screen with **Police**, **Fire** and **Medical** buttons. See [Alarms, troubles and activity](/user/alarms-troubles/#use-the-emergency-screen). |

**Troubles** is not on the rail. To open **Troubles**, push the yellow trouble count in the top bar.

## Settings

The gear opens **Settings**. Some sections ask for a master or installer code. **Settings** does not open while the panel is armed or while an alarm sounds.

On a keypad panel, **Users**, **Integrations**, **Automations**, **Smart Home** and **Walk test** are not in **Settings**.

## Enter a code

<Aside type="note">
The panel does not submit a code when you type the last digit. Codes can have from 4 to 10 digits, so the panel waits for the check mark.
</Aside>

Type the digits of your code, then push the check mark. To correct a digit, push the delete key on the left of **0**.

If you enter too many wrong codes, the keypad locks for a while. If you do not know your code, ask the person who manages users. Do not guess.

## Wake the screen

After a time without a touch, the panel shows the screen saver. The screen saver shows the time and the alarm state. Push the screen to return to the panel. To change when the screen saver starts, see [Screen and sound](/user/display-sound/).
