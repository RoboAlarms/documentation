Chime makes a short sound when a chime-enabled zone opens while its partition is disarmed. It is separate from arming the alarm.

## Change chime

1. Disarm the partition controlled by this keypad.
2. Select **Chime** on the left rail.
3. If a code pad opens, enter an authorized code and select the **check mark**.
4. Check the chime indicator to confirm the new state.

<PanelShot src="/images/panel/chime.png" alt="Turn chime on confirmation with a code pad" caption="Your installer chooses whether changing chime requires a code." />

If **Chime needs a code** is off, selecting Chime switches it immediately. Chime on/off is controlled from the **Chime** rail button; its volume is under **Settings > Screen and sound**. Chime state belongs to the current partition; brightness, volume, key clicks and screen-saver settings belong to this keypad.

## A door does not chime

Check that this keypad's partition is disarmed and chime is on. Then open **Zones** and confirm that the correct zone changes when the door opens. The installer must also enable **Chime** for that individual zone.

If the zone never changes, investigate the sensor first. Changing the chime setting cannot fix a sensor connection.
