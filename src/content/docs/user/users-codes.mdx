**Where:** Settings > Users<br />
**Access:** installer or system master for all users; a partition master for eligible users within their assigned partitions<br />
**Before you begin:** every partition affected by a user change must be disarmed and not in alarm.

## Add a user

1. Open **Settings > Users** and authenticate with your own authorized code.
2. Select **Add a user**.
3. Enter the new user's code twice when **Code for the new user** appears.
4. On the new user's page, select **Name** and enter a recognizable name. The name appears in the event log.
5. Open **What this code can do** and choose an authority you are allowed to assign. A partition master cannot assign **Partition master**.
6. If the page offers **Partitions**, choose the areas this code may use. The user must keep at least one partition.
7. Return to the list and verify the name, authority and partition access.

Codes must be unique and contain 4–10 digits, subject to the installer's minimum length.

## Choose an authority

| Authority | What it allows |
| --- | --- |
| **Standard** | Everyday arming, disarming, bypass and chime in assigned partitions |
| **Arm only** | Arm assigned partitions; cannot disarm or bypass |
| **Guest** | Arm and disarm a partition only when that same guest armed it |
| **Partition master** | Manage permitted lower-level users within assigned partitions |
| **Duress** | Normal code operation plus a silent duress event |

The installer and system master can manage all users. A system master cannot change or remove the installer. A partition master manages only standard, arm-only, guest and duress users whose partition access stays within the partition master's own access. A partition master cannot create another partition master. The installer and system master have access to every partition.

Only the installer and system master can assign **Partition master** authority. The manager of a user can set or remove that user's Panel Manager sign-in where available; only the installer may set the installer's sign-in. A password set for somebody else is temporary: that person chooses a replacement at first sign-in. Panel Manager sign-in uses a browser password, not the keypad code.

Duress silently records and reports a duress event. Creating a duress code does not provide a monitoring service or guarantee that help is dispatched.

## Choose partition access

On a panel with more than one partition in use, a user's page includes **Partitions**. Turn on each named area where that person's code should work. The user must retain at least one partition. Installer and system-master accounts always cover every partition; their access is fixed.

Partition access affects which keypads and alarm areas the user can operate and which users a partition master may manage. It does not move zones between areas; the installer configures zones separately. Ask the installer which physical area each partition name represents. See [Partitions and your code](/user/partitions/) for everyday use.

## Change or remove a code

Open the person's page and select **Change the code**, then enter the new code twice. Existing codes are never displayed. Select **Delete this user**, review the confirmation and select **Delete** to remove access. The installer, system master and currently signed-in user cannot be deleted from this page.

The installer or system master can change codes and names for users they manage, and can assign roles and partitions to eligible users. The installer and system-master roles are fixed, and an account cannot change its own authority or partition access. A system master cannot manage the installer. A partition master can manage only eligible users within their assigned areas.

## Factory-code reminder

The **Factory codes · Tap to change** banner opens a flow for changing a currently used factory code. The installer can also replace the installer and master codes from **Settings > About > Installer > Installer and master codes** in installer mode. Installer mode is a protected installer area; it is not the same as an ordinary user's code page.

If a code does not work, stop rather than guessing: repeated failures can lock the keypad temporarily. Ask the installer or the person who manages users to check your authority and partition access. See [access and permissions](/reference/permissions/) for the complete access rules.
