A **partition** is an alarm area that can be armed and disarmed separately from other areas. The installer gives each partition a name and assigns zones and keypads to it. A partition is a software grouping; it does not by itself mean there is a separate physical panel, siren or monitoring connection.

## Use the keypad for its assigned area

The Home and Zones screens show the partition assigned to that keypad. The current touchscreen has no Home control for switching to another partition. Arm or disarm its area as described in [Arm and disarm](/user/arming-disarming/). If a keypad does not show the area you expected, ask the installer which partition it controls. Do not assume that disarming one partition disarms the others.

## Check which areas your code covers

Ask the person who manages users or the installer to review your access in **Settings > Users > your name > Partitions**. That row appears when more than one partition is in use. Your code must have access to the partition operated by a keypad. Installer and system-master codes have access to every partition.

If you have a **Partition master** account, you can manage eligible lower-level users only within your own assigned areas. The installer and system master can manage users across the system. See [Users, codes and partitions](/user/users-codes/) for the authority rules.

## If something looks wrong

If your code is refused, ask the installer or user manager to check both your authority and partition access. A user change can be made only while every affected partition is disarmed and quiet. Contact the installer if a keypad shows the wrong area, zones are assigned to the wrong area, or one partition's armed state does not match the intended operation.
