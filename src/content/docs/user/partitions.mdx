A **partition** is an area of the home that arms and disarms separately, for example the house and a studio. Use this page to switch the partition on the panel and to check where your code works.

Most homes use one partition. Then this page does not apply to you.

<Aside type="note" title="Before you start">
- The installer set up more than one partition.
- To switch, the installer must allow partition switching on this panel.
</Aside>

## How partitions work

- The installer gives each partition a name and puts each zone in one partition. The panel can have up to four partitions.
- Each panel has a default partition. The **Security** and **Zones** screens show the partition that the panel shows now.
- To arm or disarm one partition does not change the other partitions.
- A partition is a setting in the software. It does not add a separate panel, siren or monitoring service.

## Switch the partition

If switching is allowed, the **Security** screen shows a row below the state ring. The row shows the name of the partition and **Switch partition**.

<PanelShot src="/images/panel/partitions-switch-row.png" alt="The Security screen with a row below the state ring that says Home and Switch partition" caption="The row below the state ring shows the partition that the panel shows now." />

<Steps>

1. On the **Security** screen, push the **Switch partition** row.

   The panel shows **Choose a partition** with a list of the partitions. A check mark shows the current partition.

   <PanelShot src="/images/panel/partitions-chooser.png" alt="The Choose a partition list with Home and Studio" caption="Push the name of the partition that you want to use." size="small" />

2. Push the name of the partition.

   The **Security** and **Zones** screens show that partition.

3. Arm or disarm as usual. See [Arm and disarm](/user/arming-disarming/).

</Steps>

<Aside type="tip" title="Check the result">
The row below the state ring shows the name of the partition that you chose.
</Aside>

When nobody touches the panel for a time, the panel returns to its default partition. The installer sets this time. From the factory, it is 30 seconds. The installer can also turn off the automatic return.

## Check where your code works

Your code works only in the partitions that the person who manages users chose for you. Ask that person to check **Settings > Users >** your name **> Partitions**. The installer and system master codes work in all partitions.

A **Partition master** code can manage users only in its own partitions. See [Users and codes](/user/users-codes/).

## For the installer

Set the partition of this panel in **Settings > About > Installer > Keypads and devices > This panel**:

| Setting | What it does | Default |
| --- | --- | --- |
| **Default partition** | The partition that the panel shows and returns to. | Partition 1 |
| **Allow partition switching** | Shows the **Switch partition** row. Off locks this panel to its default partition. | Off |
| **Return after inactivity** | The seconds without a touch before the panel returns to its default partition, from 1 to 3600. | 30 |
| **Never return automatically** | The panel stays on the chosen partition. | Off |

See [Partitions](/installer/partitions/) and [Keypads](/installer/keypads/).

## If it does not work

| Problem | Do this |
| --- | --- |
| The **Security** screen has no **Switch partition** row. | Switching is not allowed, or only one partition is in use. Ask the installer. |
| The panel says **Partition switching unavailable**. | On a keypad panel, check that the alarm panel is on and on the same Wi-Fi. |
| The panel does not accept your code in a partition. | Your code does not work in that partition. Ask the person who manages users. |
| The panel shows a different partition than before. | The panel returned to its default partition. Switch again. |
| A zone is in the wrong partition. | Ask the installer to change the zone. |
