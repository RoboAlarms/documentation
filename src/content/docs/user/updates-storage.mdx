Use this page to install a new software version on the panel, and to check or remove the SD card.

## Install an update

<Aside type="note" title="Before you start">
- You need a system master code or the installer code.
- All partitions must be disarmed, with no alarm. Settings open only then.
- The panel must be connected to the internet.
</Aside>

<Steps>

1. Open **Settings > About**.

   The top row shows the version that runs now.

2. Push **Software update**.
3. Enter your code, if the panel asks for one.
4. To ask the update server now, push **Check again**.

   If a new version is available, the panel shows it.

5. Push **Install version** and the version number.
6. Read the question, and then push **Install**.

   The panel downloads and checks the update.

</Steps>

<PanelShot src="/images/panel/updates-offered.png" alt="Software update page with Version 0.6.1 is ready to install and the Install version 0.6.1 button" caption="The top row shows the new version and the version that you have now." />

<Aside type="caution" title="Caution">
Keep the power connected until the update is complete. The panel needs power to download, check and install the update.
</Aside>

The panel keeps protecting while it downloads and waits. It restarts when all of these are true:

- All partitions are disarmed.
- No alarm sounds.
- Installer mode is off.
- No walk test runs.

After the restart, the panel tests the new version. If the test fails, the panel goes back to the earlier version and shows **Rolled back**.

<Aside type="tip" title="Check the result">
Open **Settings > About**. The top row shows the new version.
</Aside>

Nothing installs until a person pushes **Install**. To stop an update, push **Stop the update**, and then push **Stop it**. When the panel starts to restart, you cannot stop the update.

### Keypad panels

Keypads update with this panel. They restart together once everything is disarmed.

<PanelShot src="/images/panel/updates-keypads.png" alt="Keypads section of Software update with three keypads and the update state of each" caption="Each keypad shows its version and how far its update is." size="medium" />

On a keypad panel, **Software update** shows the alarm panel that its updates come from.
### Language and voice packs

Some updates also bring language packs and voice packs. The panel gets them from its update server with the update. There is no separate download button. The voice announcements need a voice pack. See [Screen and sound](/user/display-sound/#voice-announcements).

### Update server and channel

The installer sets the update server and the update channel at **Settings > About > Installer > Updates**. The default server is the RoboAlarms server, and the default channel is **Stable**. **Beta** and **Alpha** have newer versions that are less tested. **Dev** is for developers.

Do not ask the installer to change the server or channel to work around an update error. Ask the installer to find the cause instead.

To update the panel over USB, use the [Flasher](/flasher/update/). The system master and the installer can also use [Panel Manager](/panel-manager/updates/).

## View and manage the SD card

<Aside type="note" title="Before you start">
- Anyone can see the state of the card.
- You need a system master code or the installer code to remove or format the card.
</Aside>

<Steps>

1. Open **Settings > About**.
2. Push **SD card**.

   The panel shows the state of the card, the free space, the format and the model.

3. If the panel finds no card, push **Check for a card**.
4. Before you take out the card, push **Safely remove**. Wait until the state changes.

</Steps>

<PanelShot src="/images/panel/updates-sd-card.png" alt="SD card page with Ready, the free space, Safely remove, the card details and Format the card" caption="Push Safely remove before you take out the card." size="medium" />

The panel can use cards with the FAT12, FAT16 or FAT32 format. It cannot use exFAT. The panel does not keep its settings on the card. A card error does not change the alarm settings.

### Format the card

<Aside type="caution" title="Caution">
Copy the files that you need before you format the card. **Format the card** erases all files and partitions on the card.
</Aside>

Push **Format the card**, read the question, and then confirm. Keep the power connected until the format is complete. A format is not a secure erase.

## If it does not work

| Problem | Do this |
| --- | --- |
| **Software update** asks for a code. | Enter a system master code or the installer code. |
| The panel shows no new version. | Push **Check again**. Make sure the connection check passes. See [Wi-Fi, network and time](/user/network-time/#check-the-connection). |
| The update waits. | Disarm all partitions, silence any alarm and end any walk test. Ask the installer to leave installer mode. |
| The panel shows **Rolled back**. | The new version did not start correctly, and the panel uses the earlier version. Tell the installer. |
| The panel does not find the SD card. | Push **Check for a card**. Use a card with the FAT32 format. |
