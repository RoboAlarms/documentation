## Check or install an update

**Where:** Settings > About > Software update<br />
**Access:** a system master or installer code is required to open and manage this page. Settings cannot be opened while a partition is armed or in alarm.

1. Open **Settings > About** and note the running version.
2. Open **Software update**. Select **Check again** if you want the panel to ask its update server now; the page also shows its check result and when it last checked.
3. If a version is offered, read its version and whether the panel marks it as an important fix.
4. Select **Install version ...** and confirm with **Install** when you are ready. The panel downloads and verifies the signed image before it can install.
5. Keep power connected. If the verified update is waiting, the screen explains what must become safe first. The panel restarts when every partition is disarmed, the alarm is silent, installer mode is off and any walk test has ended.
6. After restart, allow the panel to test the new version. Reopen **Software update** or **About this panel** to confirm the result.

<PanelShot src="/images/panel/update.png" alt="Software update page with a version offered by the update server" caption="Review the offered version before installing it." />

Nothing installs without a person choosing **Install**. The panel keeps protecting while it downloads and waits to restart. You can select **Stop the update** while it is still stoppable; confirm **Stop it**. Once the panel has begun restarting to install, it cannot be stopped from this page. A failed start-up self-test returns to the previous firmware and reports **Rolled back**; the rolled-back version did not become the running version.

### Update server and channel

The update server and release channel are installer settings, separate from checking or installing a release. The installer finds **Updates** under **Settings > About > Installer**. There, **Update server** and **Update channel** are available only to the installer. The default server is the RoboAlarms server; changing it requires the installer to verify the server and, when its signing key is not already trusted, review and accept its key fingerprint. Changing the server replaces the previously accepted key. Do not change these values to work around an update error; ask the installer to verify which source the panel should trust.

The channel controls which releases the server offers: **Stable**, **Beta**, **Alpha** or **Dev**. Stable is the default. Beta and Alpha contain newer, less-tested releases; Dev is for developers. Choosing a channel triggers a check, but it does not install a release by itself.

Some releases may list signed language and asset packs in addition to firmware. The panel fetches matching packs listed by its update server; there is no separate pack download button on this page. A ready voice pack is required for the voice controls described in [Screen and sound](/user/display-sound/). A pack being available from a development build or test server does not mean it is included in every release.

For a USB update, use [RoboAlarms Flasher](/flasher/update/). [Panel Manager](/panel-manager/updates/) provides browser access for installers with Developer mode enabled; it is an installer workflow, not an ordinary household-user update path.

## View and manage an SD card

**Where:** Settings > About > SD card<br />
**Access:** anyone can view the card state; a system master or installer code is needed for card actions.

The **SD card** row reports the card state. Open it to see status and, when available, its filesystem and model. If no card is detected, select **Check for a card** to check again. With a supported card, use **Safely remove** and wait for the state to update before removing it. FAT12, FAT16 and FAT32 are supported; exFAT is not. A card error or unsupported filesystem does not mean panel settings are stored on the card.

<PanelShot src="/images/panel/storage.png" alt="About this panel SD card status and card details" caption="The SD card page reports card state and details when a card is available." />

**Format the card erases all files and partitions on that card.** Review the confirmation carefully and keep panel power connected until formatting finishes. Formatting is not a secure erase or a general fix for every storage problem. If the card contains files you need, back them up before formatting.

The SD card page reports card storage only. It does not provide a browser for internal flash or removable access to panel settings. Ask the installer for help if **Check for a card** cannot detect a supported card or a storage error persists.
