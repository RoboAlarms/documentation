Use the **Delays and arming** page to set how the alarm behaves on the whole panel. The settings include the siren time, which applies to every siren that the panel sounds.

<Aside type="note" title="Before you start">
- You need the installer code.
- Disarm every partition.
- Write down the current values before you change them.
</Aside>

## Open the page

<Steps>

1. Push **Settings**.
2. Push **About**, and then push **Installer**.
3. Enter the installer code.
4. Under **How the alarm works**, push **Delays and arming**.

   The panel shows the delays first. The line under the title says **Saved when you go back**.

5. Change the settings that you need.
6. Push the back arrow to save the changes.

</Steps>

<PanelShot src="/images/panel/delays-and-arming.png" alt="Delays and arming page with Exit time, Entry time 1, Entry time 2 and Report delay" caption="Use the minus and plus buttons to change a time; the panel saves when you go back." />

**Exit time**, **Entry time 1** and **Entry time 2** on this page belong to the partition that this panel shows. Set the times of other partitions in **Installer > Partitions**. For more information, see [Set up partitions](/installer/partitions/).

If the entry time plus the report delay is more than 60 seconds, the page shows a warning. If no zone is a night zone, the page tells you that **Night** arms like **Stay**.

## Delays and sirens

| Setting | What it does | Default |
| --- | --- | --- |
| **Exit time** | The time to leave after the panel arms. | 60 s |
| **Entry time 1** | The time to disarm after the main door opens. | 30 s |
| **Entry time 2** | The entry time for a second door, for example a garage door. | 45 s |
| **Report delay** | If someone disarms within this time, the panel does not send the burglary alarm. It does not add entry time. **Report at once** turns it off. | 30 s |
| **Siren time** | How long a burglary alarm sounds. **Until disarmed** keeps the sirens on until someone disarms. | 4 min |
| **Fire and CO sirens stop by themselves** | On: fire and CO sirens stop after the siren time. Off: they sound until someone silences them. The panel recommends off. | Off |
| **Cancel window** | If someone disarms this soon after the panel reported an alarm, the panel sends a cancel. | 5 min |

**Siren time** and **Fire and CO sirens stop by themselves** apply to every siren kind: wired sirens, 433 MHz sirens, and Zigbee and Z-Wave sirens. To add and test sirens, see [Set up sirens and outputs](/installer/sirens/).

<Aside type="danger" title="Warning">
Do not turn on **Fire and CO sirens stop by themselves** without a reason. A fire or CO siren that stops can let people stay in a dangerous building.
</Aside>

## Alarms

| Setting | What it does | Default |
| --- | --- | --- |
| **Alarm limit** | A zone that causes this many alarms while the panel is armed stops until the next disarm. | 2 times |
| **Cross-zone time** | Two cross-zoned sensors must both trip within this time. | 300 s |
| **Fire verification** | A verified smoke detector must trip again within this time. | 90 s |
| **Smoke detector reset** | How long smoke detectors lose power when they reset. | 6 s |
| **Panic keys** | What the keypad keys A, B and C send when a person holds them for two seconds. | A: Police, B: Medical, C: Fire |
| **Trouble beeps** | Which troubles make the keypad beep. | All except mains power loss and clock not set |

The **Panic** page on the screen always offers police, fire and medical alarms. **Panic keys** changes only the A, B and C keys.

## Arming and chime

| Setting | What it does | Default |
| --- | --- | --- |
| **Auto-stay** | Away arming becomes Stay when nobody leaves through an entry door. | On |
| **Exit beeps** | The panel beeps during the Away exit time, faster in the last 10 seconds. | On |
| **Arm without a code** | A person can arm without a code. Disarming always needs a code. | Off |
| **Allow less secure automations** | Automations can disarm, unlock and open. This row shows only when the panel has automations. | On |
| **Arm remotely without a code** | Connected services, such as MQTT and Home Assistant, can arm without a code. Disarming always needs a code. | Off |
| **Quick exit** | A person can restart the exit time without a code while the panel is armed Stay or Night. | On |
| **Exit time restarts** | How many times the Away exit time starts again when someone comes back in before it ends. | 1 |
| **Recent closing** | An alarm this soon after arming is reported as a recent closing. | 120 s |
| **Chime needs a code** | On: a person needs a code to switch the chime on or off. Off: one push changes it. The chime changes only while the panel is disarmed. | On |

## Codes

| Setting | What it does | Default |
| --- | --- | --- |
| **Shortest new code** | The minimum length of a new or changed code. Existing shorter codes keep working. | 4 digits |
| **Wrong codes before lockout** | The number of wrong codes before the keypad locks. **Never lock** turns the lockout off. | 5 |
| **Lockout time** | How long the keypad refuses codes after a lockout. | 5 min |

## Power and walk test

| Setting | What it does | Default |
| --- | --- | --- |
| **Come back armed after a power cut** | On: the panel goes back to its earlier armed state after a restart. Off: the panel starts disarmed. | On |
| **Installer code recovery** | For two minutes after power-up, **Installer** opens without the code. Off: a lost installer code cannot be recovered. | On |
| **Settling time** | After power-up, zone alarms wait this long for the sensors to settle. **None** turns it off. | 60 s |
| **Walk test ends after** | The longest time a walk test runs. | 60 min |
| **Allow values outside SIA CP-01** | Allows shorter delays, more alarms for each zone and no cancel window. Use it only for special installations, never for a monitored one. | Off |

Tell the owner how the power settings work. Write the values that you chose in the handover record. The panel settings do not certify an installation to a standard.

<Aside type="tip" title="Check the result">
Open **Delays and arming** again and check the values. Then test the exit and entry route, the sirens and the panic keys as part of [Test and hand over](/installer/commissioning/).
</Aside>

## If it does not work

| Problem | Do this |
| --- | --- |
| A change does not stay. | Push the back arrow to leave the page. The panel saves only when you go back. |
| The panel refuses a change. | Disarm every partition, and then try again. |
| A value does not go lower or higher. | The SIA CP-01 limits apply. Change **Allow values outside SIA CP-01** only for a special installation. |
| The values go back after a restart. | Look for a storage trouble in **Activity**. |
