Use this page for the panel's side of the Home Assistant connection. The person who manages Home Assistant installs the RoboAlarms integration and adds the panel there. For the full steps on both sides, see [Install and pair Home Assistant](/integrations/home-assistant-setup/).

<Aside type="note" title="Before you start">
- You need the system master code or the installer code.
- The RoboAlarms integration is installed in Home Assistant.
- Someone is at Home Assistant during the pairing, or you can open it in a browser.
- Disarm every partition.
</Aside>

## Pair on the panel

<Steps>

1. Push **Settings > Integrations**.
2. Enter the system master code or the installer code.
3. Under **Smart home**, push **Home Assistant**.
4. Turn on **Home Assistant**.
5. Push **Pair with Home Assistant**, and enter the code again if the panel asks for it.

   The panel shows **Waiting for Home Assistant** for two minutes.

6. In Home Assistant, add the discovered **RoboAlarms** panel under **Settings > Devices & services**.

   The panel shows **Does Home Assistant show this code?** and a six-digit code.

7. Compare the code on the panel with the code in Home Assistant.
8. If all six digits are the same, push **Yes, allow**. If they are not the same, push **No, reject**.

</Steps>

<PanelShot src="/images/panel/ha-pair-code.png" alt="Panel asks Does Home Assistant show this code? with the buttons No, reject and Yes, allow" caption="Push Yes, allow only when Home Assistant shows the same six digits." size="medium" />

<Aside type="tip" title="Check the result">
The line under **Home Assistant** shows **On · connected and paired**. The panel and its zones show in Home Assistant under **Settings > Devices & services**.
</Aside>

## If it does not work

| Problem | Do this |
| --- | --- |
| Home Assistant does not find the panel. | Give the panel's IP address to the person at Home Assistant. Find it under **Settings > Wi-Fi and network**. |
| The two minutes end before the code shows. | Push **Pair with Home Assistant** again. |
| The panel shows **Switch the integration on first**. | Turn on **Home Assistant**, and then push **Pair with Home Assistant**. |

For other problems, see [Troubleshoot Home Assistant](/integrations/home-assistant-troubleshooting/).
