A zone is one place that the panel watches, for example the front door. A zone has two parts: how the alarm reacts (its type) and the sensor that tells the panel the state (its source). Use this page to add zones and to set them up.

<Aside type="note" title="Before you start">
- You need the installer code.
- Disarm every partition and silence any alarm.
- Set up the partitions first if the building has more than one area. See [Set up partitions](/installer/partitions/).
- For a wired sensor, wire it to a free terminal. For a radio sensor, have it near the panel and ready to trigger.
</Aside>

## Add a zone

<Steps>

1. Open **Settings > About > Installer** and enter the installer code.
2. Push **Zones**.
3. Push **Add a zone**.

   The panel shows **Where is the sensor?**.

   <PanelShot src="/images/panel/zones-source-picker.png" alt="Where is the sensor? sheet with Wired contact, Home Assistant sensor, Zigbee sensor, 433 MHz sensor and Simulator" caption="The list shows only the sources that this panel can use." size="small" />

4. Push the kind of sensor.

   For **Wired contact**, the panel shows **Pick the terminal**. For **433 MHz sensor**, it shows **Find the sensor**.

5. Trigger the sensor. For example, open and close the door.

   The panel shows which terminal or sensor answered.

6. Push the terminal or sensor.

   The panel opens the new zone's page.

7. Push **Name**. Type where the zone is, for example Front Door or Kitchen Window.
8. Push **Type**. Choose how the alarm reacts. See [Zone types](#zone-types).
9. If more than one partition is in use, push **Partition** and choose the area.
10. Push **Sensor**. Choose the kind of sensor. This sets the icon and the words for open and closed.
11. Set the options under **What it does**. See [Zone options](#zone-options).
12. Go back to save the zone.

</Steps>

<Aside type="tip" title="Check the result">
Open the **Zones** screen. Open and close the sensor. The zone changes to open, then back to closed.
</Aside>

The **Simulator** source is for tests only. It does not watch a real door. Replace it with a real source before you hand over the panel.

## The zone page

| Section | Rows |
| --- | --- |
| **The zone** | **Name**, **Spoken name**, **Type**, **Partition** (with more than one partition), **Acts as** (for an arm or disarm button) |
| **Its sensor** | **Sensor**, **Source**, and the **Sensor settings** of the source |
| **What it does** | The zone options |
| **Advanced** | **Cross-zone partner**, **Alarm limit** |

To remove a zone, push **Remove this zone** at the end of its page. The panel stops watching the sensor. The history of the zone stays in the event log.

## Zone types

| Type | Use it for |
| --- | --- |
| **Entry/exit 1** | The door that people come in by. It starts Entry time 1. |
| **Entry/exit 2** | A second door, like the garage. It starts Entry time 2. |
| **Perimeter** | Doors and windows that cause an alarm at once. |
| **Interior follower** | Motion sensors that wait while entry time runs. |
| **Interior with delay** | Motion sensors that start entry time. |
| **Trouble by day, alarm by night** | Doors that must not open. |
| **Silent burglary** | An alarm that the panel reports without the siren. |
| **24-hour silent** | A hold-up button. It is always armed and silent. |
| **24-hour audible** | A panic button. It is always armed and sounds the siren. |
| **24-hour auxiliary** | Water, freezer or medical sensors. The keypad sounds. |
| **Fire** | Smoke and heat detectors. |
| **Fire with verification** | Smoke detectors that reset once and cause an alarm on a second trip. |
| **Carbon monoxide** | CO detectors. |
| **Monitor** | A sensor that is logged and reported, but never causes an alarm. |
| **Arm Stay button**, **Arm Away button**, **Disarm button**, **Keyswitch** | A key fob, button or keyswitch that arms or disarms. |
| **Momentary exit** | A button that restarts exit time. |
| **No response** | Chime only, for example a doorbell. |

<Aside type="danger" title="Warning">
Do not use a 433 MHz sensor or a Home Assistant sensor for fire, CO or panic protection. The panel cannot tell when such a sensor stops working.
</Aside>

## Zone options

| Option | What it does |
| --- | --- |
| **Night zone** | The interior zone is also armed in Night, not only in Away. |
| **Chime** | The panel dings when the zone opens while disarmed and the chime is on. |
| **Can be bypassed** | People can bypass the zone. 24-hour zones normally cannot be bypassed. |
| **Report this zone** | On: the events of the zone go to phones and integrations. Off: they stay in the event log of the panel. |
| **Cross-zone partner** | Two sensors must both trip close together to cause an alarm. |
| **Alarm limit** | The zone stops sounding after this many alarms in one arming. **System setting** uses the value in **Delays and arming**. |

## Wired zones and end-of-line resistors

For a wired zone, open the zone page and push **Sensor settings**. The **Contact** row sets how the panel reads the sensor's contact.

On a terminal that can measure the loop, you can choose from five choices. On other terminals, you can choose **Normally closed** or **Normally open** only.

<PanelShot src="/images/panel/zones-contact-choices.png" alt="Contact sheet with Normally closed, Normally open, Closed, end-of-line resistor, Open, end-of-line resistor and Double end-of-line" caption="The text under each choice tells which sensors it is for." size="small" />

| Contact | Resistors | Use it for | What the panel detects |
| --- | --- | --- | --- |
| **Normally closed** | None | A contact that is closed while the door is shut | A cut wire shows as open. |
| **Normally open** | None | A contact that closes when it trips | A cut wire is not detected. |
| **Closed, end-of-line resistor** | 2 kOhm at the sensor, 4.7 kOhm pull-up at the terminal | Doors, windows and motion sensors | A short across the wires is a tamper. |
| **Open, end-of-line resistor** | 2 kOhm at the sensor, 4.7 kOhm pull-up at the terminal | Smoke detectors and panic buttons | A cut wire is a trouble. |
| **Double end-of-line** | Two 2 kOhm resistors at the sensor, 4.7 kOhm pull-up at the terminal | Sensors with a tamper switch | A cut or shorted wire is a tamper. |

Choose an end-of-line contact when you can. A plain contact does not show when someone cuts or shorts the wires. You can choose the end-of-line contacts only on the touchscreen, not in Panel Manager.

<Aside type="caution" title="Caution">
Fit the resistors exactly as the **Contact** choice says. If the wiring and the choice do not match, the zone shows a wrong state, a tamper or a trouble.
</Aside>

The **Response time** row sets how long the contact must stay changed before the zone changes.

| Response time | Use it for |
| --- | --- |
| 10 ms | Fast sensors, for example glass break and shock sensors |
| 350 ms | Doors, windows and motion sensors (usual) |
| 700 ms | Contacts that bounce |
| 1.2 s | Slow or noisy wiring |

## Enroll a 433 MHz sensor

<Steps>

1. Push **Add a zone**.
2. Push **433 MHz sensor**.

   The panel shows **Find the sensor**. It listens for the sensor.

3. Open the door.

   The panel shows **Heard** and the name of a sensor.

4. Close the door. For a remote or a motion sensor, trigger it again.

   The panel shows **Found it:** and the sensor that answered each time.

5. Push **Use** and the sensor name.

</Steps>

The panel groups the codes it receives by sensor and shows how often each one answered. If more than one sensor answers, trigger only the sensor that you want again. The section **Already transmitting before you started** lists signals that the panel heard before you began. They do not show that your sensor answered.

The receiver decodes selected 433 MHz sensor types. A sensor that uses 433 MHz is not always one that the panel can read. The panel does not read sensors on 345 MHz or 319.5 MHz. Check that the zone opens and closes before you rely on the sensor.

A 433 MHz sensor is not supervised. A sensor that stops sending cannot tell the panel. Fixed-code signals can also be copied. If the sensor sends tamper or low-battery codes, add them on the sensor settings page with **Find the tamper code** and **Find the low-battery code**. Otherwise, change the batteries as part of regular maintenance.

The **433 MHz** page in the installer menu lists every 433 MHz zone and when the panel last heard it. See [Sirens and outputs](/installer/sirens/#the-433-mhz-page).

## If it does not work

| Problem | Do this |
| --- | --- |
| **Every zone is in use** | Remove a zone that you do not use. |
| No terminal answers when you open the door | Check the wiring between the terminal and GND. |
| A wired zone shows a tamper or trouble at once | Check that the resistors match the **Contact** choice. |
| A 433 MHz sensor is not found | Trigger the sensor near the panel. Check that the **Receiver** row on the **433 MHz** page shows **Working**. |
| Several sensors answer | Trigger only the sensor you want, then choose the one that answered each time. |
