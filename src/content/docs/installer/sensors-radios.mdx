The panel can read sensors from its wired terminals and from three radios: 433 MHz, Zigbee and Z-Wave. Use this page to choose a source for each zone, to look after the radios and to set Zigbee and Z-Wave sirens.

The source picker in **Add a zone** shows only the sources that this panel can use. A source in the list does not prove that the module or the sensor is connected. Test each sensor at the panel before you rely on it.

<Aside type="note" title="Before you start">
- You need the installer code.
- Disarm every partition. Pairing, removal, radio resets and radio updates are done only in installer mode with everything disarmed.
- Tell the person responsible for the building. A radio change can stop sensor reports for a while.
</Aside>

## Choose a source

| Source | What it is | Do not use for |
| --- | --- | --- |
| **Wired contact** | A contact wired to the panel's terminals | |
| **433 MHz sensor** | A sensor that the panel learns when you open and close it | Fire, CO and panic |
| **Zigbee sensor** | A sensor paired to the panel's own Zigbee radio | |
| **Z-Wave sensor** | A sensor paired to the panel's Z-Wave radio | Fire and CO, if added without encryption |
| **Home Assistant sensor** | Any sensor that Home Assistant knows | Fire, CO and panic |

For the physical wiring and the modules, use the module maker's instructions and [RoboAlarms hardware](https://roboalarms.com/hardware/).

## Wired terminals

Wire the contact between a terminal and GND. Then add a zone with the **Wired contact** source and set its **Contact**. See [Wired zones and end-of-line resistors](/installer/zones/#wired-zones-and-end-of-line-resistors).

A terminal is used either by a zone or by an output. To use a terminal for a siren, a strobe or another output, see [Sirens and outputs](/installer/sirens/).

## 433 MHz sensors

The panel needs a 433 MHz receiver. Record the receiver in the Flasher's **Panel and parts** step. See [Connected parts](/flasher/connected-parts/). The Flasher's receiver test only shows signals. It does not add a sensor.

To add a sensor, add a zone with the **433 MHz sensor** source. See [Enroll a 433 MHz sensor](/installer/zones/#enroll-a-433-mhz-sensor).

The **433 MHz** page in the installer menu shows the state of the receiver and the transmitter, the 433 MHz zones and the 433 MHz sirens. See [The 433 MHz page](/installer/sirens/#the-433-mhz-page).

<Aside type="danger" title="Warning">
Do not use a 433 MHz sensor for fire, CO or panic protection. A 433 MHz sensor that stops sending cannot tell the panel, and its fixed-code signal can be copied.
</Aside>

## Zigbee

The panel's Zigbee radio is an ESP32-H2 module. Open **Settings > About > Installer > Zigbee** to see the radio and its devices.

<PanelShot src="/images/panel/radios-zigbee-page.png" alt="Zigbee page with Radio Working, Add a device, Add with an install code, Remove a device and Install codes waiting" caption="The Radio row shows the state of the Zigbee radio." size="medium" />

<Steps>

1. Open **Settings > About > Installer** and enter the installer code.
2. Push **Zigbee**.
3. Push **Add a device**.

   The panel listens for 3 minutes.

4. Put the device in its pairing mode, as its maker describes.

   The panel shows the device when it joins.

5. Add a zone with the **Zigbee sensor** source and choose the device. See [Set up zones](/installer/zones/).

</Steps>

If the device label has an install code, push **Add with an install code** instead of **Add a device**. You can also start pairing from the zone: push **Source**, then **Zigbee sensor**.

If the panel says that the radio cannot be used or that its software is missing, prepare the module with the Flasher's **Zigbee module** tool. Connect the module to the computer on its own USB port. See [Connected parts](/flasher/connected-parts/).

<Aside type="caution" title="Caution">
Do not push **Reset the Zigbee network** unless you are ready to pair every Zigbee device again. The reset disconnects all of them.
</Aside>

## Z-Wave

Open **Settings > About > Installer > Z-Wave** to see the radio and its devices.

<Steps>

1. Open **Settings > About > Installer** and enter the installer code.
2. Push **Z-Wave**.
3. Push **Add a device**.
4. Put one device in its pairing mode, as its maker describes.
5. Follow the security choices on the panel. Choose Security 2 when the device supports it, and type its printed PIN when the panel asks.
6. Add a zone with the **Z-Wave sensor** source and choose the device input.

</Steps>

If the panel adds a device without encryption, it warns that the radio signal can be copied. Do not use that device for fire or CO protection.

The panel uses only the inputs that it can read from a device. A device name on the screen does not mean that every feature of the device works.

<Aside type="caution" title="Caution">
A change of **Region** can stop devices that use another frequency band or Long Range. **Reset the Z-Wave network** starts a new network and disconnects every device. After either change, you must pair those devices again.
</Aside>

### Update the Z-Wave radio

The Z-Wave radio has its own software. The panel checks for an update only when you ask. Nothing installs by itself.

<Aside type="caution" title="Caution">
Keep the panel powered during a radio update. Z-Wave sensors are not heard for up to 15 minutes, and arming waits until the radio is back.
</Aside>

<Steps>

1. Open **Settings > About > Installer** and enter the installer code.
2. Push **Z-Wave**.
3. Push the **Radio** row.

   The panel shows the **Z-Wave radio** page.

4. Push **Check for an update**.
5. If the panel shows **Install version** and a version number, push it.
6. Confirm the installation.

   The radio installs the new software, then restarts.

</Steps>

You can also install a file from the radio's maker from an SD card:

<Steps>

1. Copy the maker's .gbl file to the top folder of the SD card, or to a folder named zwave. Copy only one .gbl file.
2. Put the card in the panel.
3. On the **Z-Wave radio** page, push **Install from an SD card**.
4. Push **Update** to confirm **Update the radio from the SD card?**.

</Steps>

If no update is found, the panel shows **No update was found for this radio**. You can still install the maker's file from an SD card or from Panel Manager.

<Aside type="tip" title="Check the result">
The **Z-Wave radio** page shows **Updated** and the new version. The **Radio** row shows **Working**.
</Aside>

## Sirens on Zigbee and Z-Wave

You set a Zigbee or Z-Wave siren on its device page under **Zigbee** or **Z-Wave**, not under **Sirens and outputs**. The **Siren time** in **Delays and arming** applies to these sirens too.

| Setting | Zigbee siren | Z-Wave siren |
| --- | --- | --- |
| **Burglary and panic** | Yes. A silent panic stays silent. | Yes. A silent panic stays silent. |
| **Fire and CO** | Yes. Its fire sound for fire, its emergency sound for CO. | Yes. Its fire tone for fire, its CO tone for CO. |
| **Partitions** | The partitions whose alarms it sounds for | The partitions whose alarms and chirps it follows |
| **Also sounds for** | Other partitions' alarms, never their chirps | Other partitions' alarms, never their chirps |
| **Strobe with it** | Its own light, while it sounds | |
| **Chirp when arming and disarming** | One chirp to arm, two to disarm | Its arm and disarm tones |
| **Volume** | **Low**, **Medium**, **High** or **Very high** | **Its own** or a percentage |
| **Test it** | Sounds it for 2 seconds | Sounds it for 2 seconds |
| **Supervision** | A siren trouble when it is not heard. It cannot be turned off. | A siren trouble when it is not heard. Default **After 4 h**. It cannot be turned off. |

A Zigbee smoke detector with a sounder also has siren settings. Its own sounder can sound with the panel's alarms, like a siren. The panel can use up to four Zigbee sirens.

If a siren page shows **The panel doesn't sound it yet: turn on what it sounds for.**, turn on **Burglary and panic** or **Fire and CO**.

<Aside type="danger" title="Warning">
Tell the people in the building before you push **Test it**. A siren is loud enough to hurt your hearing near it.
</Aside>

## Clock and other modules

The Flasher can test a battery-backed clock module. The touchscreen and Panel Manager let you set the time by hand only when the panel can keep the time. See [Connected parts](/flasher/connected-parts/).

Before any Flasher job that can restart the panel, disarm the panel and leave it idle on its own screen. See [Update RoboAlarms with the Flasher](/flasher/update/).

## If it does not work

| Problem | Do this |
| --- | --- |
| **Only in installer mode, with everything disarmed** | Enter the installer code and disarm every partition. |
| **The radio is busy: try again when it's done** | Wait until the radio finishes, then try again. |
| A Zigbee device does not join | Bring it near the panel, push **Add a device** again and put the device in pairing mode. |
| **No .gbl file on the SD card** | Copy the radio's file to the top folder of the card, or to a folder named zwave. |
| **More than one .gbl file on the SD card** | Leave only the file that you want to install. |
| A siren is not heard in a test | Check its power and signal. Open its page and check **Supervision**. |
