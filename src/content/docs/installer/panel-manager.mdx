Panel Manager lets you change the panel's settings from a browser on the same network. You turn it on at the panel.

<Steps>

1. Push **Settings > About > Installer**, and enter the installer code.
2. Under **This panel**, turn on **Panel Manager**.

   The row shows the panel's address and its certificate.

3. To sign in as the installer from a browser, turn on **Browser sign-in**.
4. Type a new password for the browser.

   The password is not the installer code. The row shows the user name for the sign-in.

</Steps>

To change the password later, push **Change the browser password**. For the first connection and all Panel Manager tasks, see the [Panel Manager guide](/panel-manager/).
