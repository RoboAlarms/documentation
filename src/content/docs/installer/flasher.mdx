RoboAlarms Flasher is the desktop tool for installing and maintaining panel firmware over USB. The current guide is now organized as its own section:

- [Get started with the Flasher](/flasher/)

## Before you start

See [what to prepare before connecting](/flasher/#before-connecting): matching firmware, a data cable, stable power and an idle panel.

## Connect and identify the panel

Follow [Connect and identify the panel](/flasher/#what-the-first-check-does) to understand the read-only running-firmware check and the chip-loader check.

## Install RoboAlarms

Use the [install guide](/flasher/install/) for the eight-step setup, optional-parts plan, review, backup and first install.

### Install, Update, Reset, and Restore

Compare [Install, Update, Reset and Restore](/flasher/backups/#choose-the-right-operation) before starting a job.

## Update an existing panel

Follow the [update guide](/flasher/update/) to keep settings and understand layout and downgrade checks.

## Check connected parts

See [connected parts](/flasher/connected-parts/) for choosing a receiver, clock or Zigbee module.

### Test a 433 MHz receiver

The [receiver test steps](/flasher/connected-parts/#test-a-433-mhz-receiver) explain what the Flasher reports and how to enroll a sensor.

### Check the battery-backed clock

The [clock test steps](/flasher/connected-parts/#battery-backed-clock) explain the reading and time-setting control.

## Advanced tools

Open the [advanced tools guide](/flasher/troubleshooting/#advanced-tools) for ports, Console, Hardware, Backups, Software and Logs.

## If something goes wrong

Use [Flasher troubleshooting](/flasher/troubleshooting/#if-something-goes-wrong) for port, power, detection, write and startup problems.

The Flasher is separate from [Panel Manager](/panel-manager/), which configures a running panel in a browser over the network. For physical board and module information, see [RoboAlarms hardware](https://roboalarms.com/hardware/).
