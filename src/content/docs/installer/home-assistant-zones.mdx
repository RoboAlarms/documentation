A zone can use a Home Assistant binary sensor as its sensor. Use this page to connect a shared Home Assistant sensor to a zone and test it.

<Aside type="note" title="Before you start">
- You need the installer code.
- The panel is paired with Home Assistant. See [Connect Home Assistant](/installer/home-assistant/).
- The sensor is in **Entities the panel may use as zones** in the integration options. See [Share Home Assistant entities](/integrations/home-assistant-sharing/).
- The sensor changes state correctly in Home Assistant.
</Aside>

<Aside type="danger" title="Warning">
Do not use a Home Assistant sensor for a fire, CO, panic or other 24-hour zone. The sensor needs Home Assistant and the network, and the panel does not trust it for these zones.
</Aside>

## Connect the sensor to a zone

<Steps>

1. Push **Settings > About > Installer**, and enter the installer code.
2. Push **Zones**.
3. Add a zone, or open the zone that gets the sensor.
4. For a new zone, push **Home Assistant sensor** on **Where is the sensor?**. For an existing zone, scroll to **Its sensor**, push **Source** and choose **Home Assistant sensor**.

   The panel shows **Pick the sensor** with the shared sensors.

5. To search, push **Find the sensor** and type a part of the name, the room or the entity ID.
6. Push the sensor that the zone uses.
7. Push the back arrow to save the zone.

</Steps>

<PanelShot src="/images/panel/ha-zone-sensor-pick.png" alt="Pick the sensor page with Find the sensor and three Home Assistant sensors with their rooms and states" caption="Each shared sensor shows its room and its state; check both before you pick one." size="medium" />

## Test the sensor

<Steps>

1. Open the zone again.

   The top of the zone page shows the state and **Home Assistant · Needs the network**.

2. Open and close the door or window, or walk past the motion sensor.
3. Check that the state at the top of the zone page changes, and then goes back.
4. Run a walk test to check the zone with the other zones. See [Test and hand over](/installer/commissioning/).

</Steps>

<PanelShot src="/images/panel/ha-zone-bound.png" alt="Zone page with the state Open and the source line Home Assistant, Needs the network" caption="The top of the zone page shows the sensor's state and its source." size="medium" />

If Home Assistant or the network stops, the zone shows **Not reporting** after the time in **Unreachable after**. The panel does not take an unavailable sensor as closed. Tell the owner that this zone needs Home Assistant and the network.

<Aside type="tip" title="Check the result">
The zone's state on the panel follows the sensor. A walk test shows the zone as tested.
</Aside>

## If it does not work

| Problem | Do this |
| --- | --- |
| The sensor is not in **Pick the sensor**. | Add the sensor to **Entities the panel may use as zones** in Home Assistant. Check that the panel is still paired. |
| **That sensor isn't available** | Check the sensor in Home Assistant. It must not show as unavailable. |
| The zone shows **Not reporting**. | Check the connection to Home Assistant on **Settings > Integrations**. Check the sensor in Home Assistant. |
| The zone shows open when the door is closed. | Check that you picked the correct sensor. Check the sensor's state in Home Assistant. |
